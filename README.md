# PCF-Light

主要機能に絞って軽量化したFANZAアフィリエイト商品サイトです。

## 現在の状態

仕様検討中です。  
現時点ではアプリケーションコードを実装していません。

## 目指す方向

- 必要な機能だけに絞る
- 初心者でも設置・設定しやすくする
- 一般的なレンタルサーバーで動作させる
- PC・スマートフォンの両方で使いやすくする
- 管理や更新の負担を抑える
- 表示と処理を軽量にする
- セキュリティの基本対策を省略しない

## 仕様について

公開画面、管理画面、API取得、自動更新、検索、分類、ランキングなどの採用範囲は、今後の検討で決定します。

仕様が決まるまでは、具体的な機能や画面構成を固定しません。

## 開発管理

仕様確定後にREADMEを更新し、実装内容をIssuesへ分割します。

実装時は作業ブランチとDraft PRを使用し、確認前にmainへマージしません。
